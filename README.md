# 🐠 Wonder Pets And Aqua

A responsive e-commerce web application for aquarium fish, pets, pet food, and accessories.

## 🌟 Features

- User Authentication (Firebase Auth)
- Product Catalog
- Search Products
- Shopping Cart
- Order Management
- Admin Dashboard
- Product Add / Edit / Delete
- EmailJS Order Notifications
- WhatsApp Contact Integration
- Responsive Mobile-Friendly Design
- Firebase Firestore Database

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Firebase Authentication
- Firebase Firestore
- EmailJS
- Git & GitHub

## 📦 Modules

### User Side
- Browse Products
- Search Products
- Add to Cart
- Checkout
- Place Orders
- Contact via WhatsApp

### Admin Side
- Admin Login
- Product Management
- Customer Order Management
- Revenue & Product Statistics
